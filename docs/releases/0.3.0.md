## 0.3.0 更新

### 记录更自由

- 自动地点支持「附近名称」和「经纬度」两种显示方式，在设置中随时切换。经纬度模式直接使用坐标，不等待地址解析；附近名称解析失败时显示坐标。手填地点始终优先。
- 五种水印模板的预设都可以添加自定义字段，例如验收编号、天气、作业区域。支持修改名称和内容、排序、显示/隐藏及确认删除，每套最多 12 个。
- 工程项目模板新增监理公司、设计公司、建设公司字段；原有预设内容保留，新字段可按需填写。

### 拍摄和界面

- 改进相机探测：只使用 CameraX 公开的镜头与缩放能力，支持已开放辅助镜头的选择，并在绑定失败时回退默认镜头。部分设备不会开放超广角或长焦，控件以实际能力为准。
- 设置页采用 Material 3 分组卡片、分段选择和更清楚的说明，外观、相机、水印、地点和存储更易查找。
- README 加入 Redmi K40 真机截图，展示拍摄页、预设文件库、自定义字段、模板及设置。

### 验证与升级

- versionCode 升至 4；继续使用原发行签名，可从正式 0.2.1 直接安装升级，保留预设和设置。
- 本地 11 项单元测试、28 项 K40 设备测试通过；实际操作验证前后摄像头拍照、保存、缩放、对焦请求、闪光灯切换和后台恢复，两张照片的方向、尺寸及文件可读性验证通过。
- K40 实际系统为 Android 13 / API 33；相机生命周期自动化本轮启动阻塞，未记为通过。辅助镜头切换与真实附近名称解析仍需进一步设备/环境验证。完整范围见 [测试记录](https://github.com/kindyear/KWatermarkCam/blob/v0.3.0/docs/TESTING.md)。

最低 Android 10，继续本机存储、无需账号和后台定位。本版本为 0.x 预发布。
