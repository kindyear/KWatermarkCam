## 0.4.0 更新

- 首次启动新增权限说明弹窗，集中申请相机和定位；系统分组确认，拒绝定位仍可拍照，后续保留手动授权入口。
- 地点只显示附近名称或经纬度，不再追加“缓存”字样；内部仍保留位置测量时间、精度和有效期判断。
- 新增房屋验收、安全巡查、物流签收、生活日常四种水印，合计九种。模板页改为分类筛选、双列样式卡片与详细预览，模板与预设内容继续独立。
- 图库新增按日期瀑布流、左右滑动浏览、缩略图带、双指缩放、双击放大与还原，并接入系统分享面板。
- 新增照片基础编辑：旋转、水平翻转、固定比例居中裁剪、黑白滤镜、亮度与对比度。全分辨率保存为新副本，原图保留；副本使用现有可恢复保存流程，避免重复叠加水印。
- 修复启动图标四角削切，使用安全区内的完整圆形图形。Android 12+ 增加品牌渐显动画，并以淡出过渡进入相机；Android 10/11 保留同形静态图标兼容方式。
- 更新用户 README、模板/图库/编辑页实机截图和开发说明；versionCode 升至 6，沿用发行签名，可直接覆盖安装正式 0.3.1 并保留数据。

功能开发期间已在 Redmi K40（Android 13 / API 33）执行 31 项设备测试，并检查授权拒绝后的拍照、图库手势、分享面板、编辑副本、新模板切换及明暗冷启动。版本更新后重新进行构建、单元测试和 Lint；具体范围见 [测试记录](https://github.com/kindyear/KWatermarkCam/blob/v0.4.0/docs/TESTING.md)。相机生命周期自动化未在本轮执行，其他 Android 版本与真实低内存/磁盘满等场景尚未实测。

图库仅显示本应用记录的照片，不读取完整系统相册；裁剪为固定比例居中裁剪，尚无自由裁剪框。MIUI 浅色原生启动窗口的状态栏图标对比度仍有限，进入应用后系统栏正常。

最低 Android 10，本版本为 0.x 预发布。手机安装请选择 APK，AAB 用于商店分发。
