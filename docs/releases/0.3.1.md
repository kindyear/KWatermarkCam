## 0.3.1 更新

- 新增 Android 原生启动页：沿用应用的相机与水印图标，深青色图标底衬，背景随系统浅色/深色模式变化。
- 使用官方 AndroidX SplashScreen，Android 12+ 接入系统启动画面，Android 10/11 使用官方兼容实现；保持单 Activity，不增加独立启动页面。
- 初始设置与预设就绪后进入拍摄页，不添加固定停留时间。启动页最多等待 2 秒，存储异常时仍可进入原有加载/错误界面，不等待相机权限、定位或镜头打开。
- versionCode 升至 5，继续使用原发行签名，可从正式 0.3.0 直接升级并保留预设与设置。

本轮连接 Redmi K40（Android 13 / API 33）验证冷启动与系统明暗启动效果；其他 Android 版本未实测。构建、单元测试、Lint 与签名核验范围见 [测试记录](https://github.com/kindyear/KWatermarkCam/blob/v0.3.1/docs/TESTING.md)。0.3.0 的拍摄/预设设备结果不作为本轮业务回归结果。

最低 Android 10，本版本为 0.x 预发布。
